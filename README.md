### [Toolmunch](https://toolmunch.com) — Browser-first tools suite
276 free online tools (PDF, image, media, text, developer, AI). **196 run entirely client-side**, so files never leave the user's device.

Rust → WebAssembly in Web Workers, WebGPU shaders, ffmpeg.wasm, tesseract.js OCR, a Rust + Axum API over MongoDB, ~300 statically generated Astro pages, offline support via IndexedDB, and a full SEO architecture.

`Astro` `React` `TypeScript` `Rust` `Axum` `MongoDB` `WebAssembly` `WebGPU` `Cloudflare`

### [Planar](https://github.com/subhamtewatia1/Planar) — Indoor mapping & wayfinding
Turns a floor plan (PDF, DXF/CAD, SVG, image or GeoJSON) into a live indoor map with a QR code that opens on any phone. Parsing, room detection and scaling all happen in the browser.

`React` `Vite` `Leaflet` `Node.js` `pdf.js` `dxf-parser` `GeoJSON`

### [MacSpace](https://github.com/subhamtewatia1/MacSpace) — Native macOS cleanup app
Smart scan, space lens, clean uninstaller, secure shredder, launch-item manager and a live system monitor in the menu bar and widgets. A safety-guard layer prevents unsafe deletions; Pro licences are Ed25519-signed and verified offline.

`Swift` `SwiftUI` `Ed25519` `macOS`

### Jan Vanni — Civic complaint redressal platform
Citizens report local issues with photos and location; authorities assign and resolve them on a live map. Five role-based dashboards, audit logs, notifications and PDF reports, secured with JWT, Google OAuth, rate limiting and input sanitisation.
